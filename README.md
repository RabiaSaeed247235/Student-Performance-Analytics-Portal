# Student Performance Analytics Portal

Front-end project built with HTML5, CSS3, and JavaScript (ES6).

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Implemented Web Development Tasks

### Week 1
- Home Page
- About Page
- Student Dashboard Layout
- Performance Report Layout
- Contact Page
- Navigation Menu
- Footer Section
- Responsive design, cards, tables, forms, and mobile navigation

### Week 2
- Functional Login Form
- JavaScript Form Validation
- Dynamic Dashboard Cards
- Student Information Tables
- Search and Filter Functionality
- Improved Mobile Responsiveness
- Interactive Navigation Menu

### Week 3
- Login and Registration Pages
- Forgot Password and Reset Password UI
- User Information stored with Local Storage simulation
- Dynamic Student Profile Page
- Student Performance Cards rendered with JavaScript
- Sorting and Advanced Search Features
- UI Animations and UX improvements
- Responsive compatibility for desktop, tablet, and mobile
